# rRecall — 기록에서 기억까지

강의·필기와 백지복습을 잇는 학습 에이전트. 2026 KHU AI Challenge (AI 문제 해결 솔루션 부문) 출품작, 팀 rRecall.

**바로 써 보기:** https://tim0700.github.io/rRecall/

설치 없이 브라우저에서 동작해요. 키가 없어도 "키 없이 튜토리얼 둘러보기"로 전체 흐름을 체험할 수 있어요.

## 무엇을 하나요
정리된 노트를 읽으며 "이해했다"고 느끼는 것과, 보지 않고 떠올릴 수 있는 것은 달라요. rRecall은 정리는 AI가, 기억을 꺼내는 일은 학습자가 맡도록 나눴어요.

1. **정리** — 강의 녹음을 글로 옮긴 대본(txt, srt, vtt)과 내가 필기한 강의자료(PDF, 사진)를 넣으면, 큰 그림부터 정리한 노트와 백지복습용 뼈대를 만들어요. 노트 문장마다 대본 근거가 붙어요.
2. **꺼내기** — 노트를 덮고 뼈대만 보며 종이에 써요. 검정 펜은 혼자 떠올린 것, 빨간 펜은 노트를 보고 고친 것이에요. 뼈대는 3단계(단어·빈칸 / 핵심 개념 / 목차만)예요.
3. **약점 고르기** — 종이 사진을 올리면 AI가 읽고, 학습자가 진짜 빈틈만 약점으로 골라요.
4. **간격 복습** — 약점은 날짜를 띄워 문제로 다시 만나요. 서로 다른 날 두 번 맞히고 나중 답이 적용·연결 문제이면 해결돼요. 노트 안에서 질문하기도 할 수 있어요.

## 사용 방법
1. ChatKHU에서 API 키를 만들어요. 앱 안의 키 연결 화면과 튜토리얼에 사진과 함께 단계별 안내가 있어요.
2. 과목을 만들고, 강의 대본과 필기 자료를 넣어 노트와 뼈대를 만들어요.
3. 종이에 백지복습을 하고 사진을 올린 뒤, 약점을 골라 복습해요.

## 데이터와 키
- AI 호출은 학생 각자의 ChatKHU 키로 ChatKHU에만 보내요.
- 키와 학습 기록은 사용하는 브라우저에만 저장돼요. 별도 서버가 없어요.
- 백업 파일에는 키가 들어가지 않아요.
- 키는 비밀번호처럼 다뤄 주세요. 노출됐다면 ChatKHU API Gateway의 API 키 관리에서 바로 삭제하고 새로 만드세요.

## 기술 구성
React + TypeScript + Vite 정적 웹앱, IndexedDB 저장, ChatKHU API Gateway(Gemini·Claude 모델) 호출.

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성
npx vitest run src/core
```
