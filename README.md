# rRecall — 기록에서 기억까지

강의·필기와 백지복습을 연계하는 학습 에이전트. 2026 KHU AI Challenge AI 문제 해결 솔루션 부문 출품작(팀 rRecall).

- 서비스 URL: https://tim0700.github.io/rRecall/
- 설치 불필요(웹 브라우저 실행). API 키 없이 튜토리얼로 전체 흐름 체험 가능.

## 개요
정리된 노트를 읽으며 얻는 친숙함과 실제 인출(recall) 가능한 지식은 구분된다. rRecall은 자료 정리와 인출 결과 판독은 AI가, 인출 자체와 약점 확정은 학습자가 수행하도록 역할을 분리한다.

## 주요 기능
1. **강의 정리**
   - 입력: 외부 STT로 변환한 강의 전사문(txt, srt, vtt), 학습자 필기가 포함된 강의자료(PDF, 이미지)
   - 출력: 상위 구조(핵심 질문, 주제 흐름)부터 서술한 강의 노트, 백지복습용 뼈대
   - 노트 문장별 전사문 근거 인용 제공
2. **백지복습 뼈대(3단계)**
   - 1단계: 단어·빈칸 및 용어별 뜻 한 줄 작성. 단어 목록은 기본 비공개, 힌트 요청 시 다른 주제 용어를 섞어 제공
   - 2단계: 핵심 용어 정의 작성
   - 3단계: 목차만 제시, 강의 전체 구조 재구성
3. **인출 결과 판독**
   - 종이 사진 또는 텍스트 입력 지원. 검정 펜은 자력 인출, 빨간 펜은 노트 참조 후 첨삭으로 구분
   - 결손 유형 분류: 용어 미인출, 뜻 누락·오류, 묶음 누락, 자기 표시 불확실, 첨삭
   - 판독 결과는 학습자 확인을 거쳐 약점으로 확정
4. **약점 간격 복습**
   - 1단계 문항(용어 인출·설명), 2단계 문항(적용·연결)
   - 오답 시 힌트 제공 후 1회 재응답
   - 해결 기준: 서로 다른 날짜에 힌트 없이 2회 정답, 후행 정답이 2단계 문항일 것
   - 해결 21일 후 장기 유지 확인 1회
5. **질의응답**: 강의 노트 범위 내 개념 질의, 이미지 첨부 지원

## 복습 일정
| 구분 | 시점 | 내용 |
|---|---|---|
| 강의 백지복습 | 강의 당일 | 1단계 |
| | 3일 후 | 2단계 |
| | 이후 14일 간격 | 2단계 반복 |
| | 학습자 선택 | 3단계 |
| 약점 문항 | 등록 다음 날 | 1단계 문항 |
| | 정답 시 3일 후 | 2단계 문항 |
| | 오답 시 | 다음 날부터 재시작 |
| | 해결 21일 후 | 장기 유지 확인 |

등록 당일 응답, 재작성 연습, 후속 질문 응답은 진도에 반영하지 않는다.

## 사용 절차
1. ChatKHU API Gateway에서 API 키 발급. 단계별 화면 안내는 앱의 키 연결 화면과 튜토리얼에 수록
2. 과목 생성 후 강의 전사문과 강의자료 업로드, 노트·뼈대 생성
3. 뼈대 기반 백지복습 수행 후 사진 업로드, 판독 결과 확인 및 약점 확정
4. 일정에 따라 백지복습 및 약점 문항 수행

## 데이터 및 보안
- AI 호출: 사용자 본인의 ChatKHU API 키로 ChatKHU API Gateway에만 요청
- 저장 위치: API 키와 학습 기록 모두 사용자 브라우저(localStorage, IndexedDB). 별도 서버 없음
- 백업 파일: 학습 기록과 첨부 자료 포함, API 키 제외
- API 키 관리: 비밀번호와 동일하게 취급. 노출 시 ChatKHU API Gateway의 API 키 관리에서 즉시 삭제 후 재발급

## 기술 구성
- React, TypeScript, Vite 기반 정적 웹 애플리케이션(해시 라우팅, 상대 경로 빌드)
- IndexedDB(`idb`) 로컬 저장
- ChatKHU API Gateway 경유 모델 호출(기본 프리셋 기준): 정리·뼈대·판독 Gemini 계열, 문항·채점·질의응답 Claude 계열. 설정에서 프리셋(절약·기본·고품질) 및 역할별 모델 선택 가능

```bash
npm install
npm run dev              # 개발 서버
npm run build            # dist/ 정적 파일 생성
npx vitest run src/core  # 핵심 로직 테스트
```
